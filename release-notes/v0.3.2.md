# GPhoto Frame 0.3.2

## 繁體中文

- 首次啟動的公開相簿網址為空白，不再內建真實分享連結；既有使用者的網址與設定繼續保留。
- Google Photos 同步快取成為本機來源的預設資料夾，方便離線使用。
- 提供中英文使用說明、固定名稱安裝檔與 SHA-256 校驗碼。

Windows 10／11 x64；需要 WebView2 Runtime，缺少時安裝程序可能需要連網下載。
請下載 `.exe`，不是 Source code ZIP。版本名稱與固定名稱的安裝檔內容相同，擇一即可。
目前未進行程式碼簽章，Windows 可能顯示安全提醒；請核對來源與 SHA256SUMS.txt，不要關閉安全防護。
公開分享相簿使用非正式分享頁解析；停用分享不會清除已下載的本機照片。

## English

- Fresh installations start with a blank album URL and no built-in real shared link. Existing user URLs and preferences are retained.
- The Google Photos download cache becomes the default local photo folder for convenient offline access.
- Bilingual documentation, a stable installer filename and SHA-256 checksums are included.

Requires Windows 10/11 x64 and WebView2 Runtime; installation may download the runtime if missing.
Download an `.exe`, not Source code ZIP. The versioned and stable-name installers are identical; choose either.
The installer is not code-signed and Windows may show a security warning. Verify its source and SHA256SUMS.txt; do not disable security protection.
Public albums are parsed through an unofficial sharing-page integration. Disabling sharing does not erase downloaded local photos.
