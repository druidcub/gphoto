# GPhoto Frame 0.3.3

## 繁體中文

- 新增「支持開發」，以外部瀏覽器開啟 PayPal。贊助為自願，不影響免費功能。
- 新增「版本資訊」，顯示目前版本、離線更新摘要與 GitHub Releases 連結。
- 新增 Windows x64 免安裝 EXE，直接執行即可；仍需 WebView2 Runtime。

安裝版（setup）與免安裝版（portable）用途不同，擇一使用；各自的版本檔名與固定檔名副本內容相同。免安裝版不建立捷徑或解除安裝項目，與安裝版共用 App Local Data 的設定及照片快取，不是隨身碟可攜資料模式，請勿同時執行兩版。

需要 Windows 10／11 x64。EXE 未簽章；請核對來源與 SHA256SUMS.txt，不要關閉安全防護。不要下載 Source code ZIP 當安裝檔。

## English

- Added voluntary PayPal support links that open in the system browser; all features remain free.
- Added version information with bundled offline history and a GitHub Releases link.
- Added a standalone Windows x64 executable. WebView2 Runtime is still required.

Choose either setup or portable. Each format has identical versioned and stable-name copies. Standalone execution creates no shortcuts or uninstall entry; it shares App Local Data settings/cache with the installed version, not USB-portable data. Do not run both simultaneously.

Requires Windows 10/11 x64. Executables are unsigned: verify the source and SHA256SUMS.txt, and do not disable security protection. Source code ZIP is not an installer.
