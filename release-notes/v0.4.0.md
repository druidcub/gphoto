# GPhoto Frame 0.4.0 — 跨平台測試版 / Cross-platform preview

## 繁體中文

- Windows／macOS 共用 Tauri 2 播放器，新增 Intel＋Apple Silicon Universal Mac 封裝。
- Mac 最低目標為 macOS 12；包含原生全螢幕、防休眠、小視窗及 Control＋Command＋F。
- 視窗切換串行化、Retina／多螢幕座標檢查、舊 WebKit 對話框及遮罩相容處理。
- 設定及快取 manifest 安全替換寫入，本機照片 ID 保留路徑大小寫。
- Google Photos 公開相簿、離線快取、完整照片排版、柔和模式與贊助入口保留。

本版本為預發行，不設為 Latest。Mac 包使用 ad-hoc 簽章，尚未完成 Developer ID 簽章及 Apple 公證，可能遭 Gatekeeper 阻擋；不要求關閉系統安全保護。macOS 12 與 Intel／Apple Silicon 實機播放驗收尚待完成，CI 成功不等於實機驗收。

Windows x64 需 Windows 10／11 及 WebView2。Windows EXE 仍未簽章，可能顯示 SmartScreen 提醒。Mac 下載 DMG 後將完整 GPhoto Frame.app 拖入 Applications，不需 WebView2。設定與快取位於各平台使用者資料目錄，不在執行檔旁；不自動更新或清除既有設定。

下載版本檔或固定檔名均可，同格式內容相同。核對本次 Release 的 SHA256SUMS.txt；Windows README 的 latest 入口仍指向上一個正式版。

## English

- Shared Tauri 2 Windows/macOS player with an Intel + Apple Silicon Universal Mac bundle.
- macOS 12 deployment target, native full screen, idle-sleep prevention, mini window and Control + Command + F.
- Serialized window transitions, Retina/multi-monitor bounds recovery, older WebKit dialog and mask compatibility.
- Safe settings/cache-manifest replacement and case-preserving local photo IDs.
- Existing public Google Photos albums, offline cache, full-photo layouts, soft mode and support links remain available.

This is a prerelease, not Latest. Mac packages are ad-hoc signed, not Developer ID signed or Apple-notarized, and may be blocked by Gatekeeper. Do not disable security protection. macOS 12 and Intel/Apple Silicon hardware playback validation remain pending; passing CI is not hardware validation.

Windows x64 needs Windows 10/11 and WebView2. Windows executables remain unsigned and may trigger SmartScreen. On Mac, download the DMG and drag the complete GPhoto Frame.app to Applications; WebView2 is not required. Settings/cache remain in the platform's user-data directory, not beside the executable. Existing settings are preserved; automatic updates are not included.

Versioned/stable-name copies of each format have identical bytes. Verify this release's SHA256SUMS.txt; Windows README latest links continue to point at the previous stable release.
